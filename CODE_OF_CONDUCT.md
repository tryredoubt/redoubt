# Code of Conduct

## Expected behavior

Be specific, honest, and constructive. Review the work, not the person.
Keep discussions technical and on topic. Do not harass anyone, publish
private information, use hate speech, or post sexual content in project
spaces.

## Reporting

Report conduct problems privately to hello@tryredoubt.com. Reports are
handled confidentially, and a report against one participant does not
exempt the reporter from the same rules.

## Enforcement

Devitechy LLC reviews reports and may warn, block, or remove a
participant from project spaces. Enforcement applies only within the
project spaces Devitechy controls: this repository and the project's
own channels. It does not govern third-party services or communities
that merely host project discussion.
